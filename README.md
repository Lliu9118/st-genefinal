This is a website I made on visualizing discrepancies between oncogenic gene mutation rates across different races. 

I used data from The Cancer Genome Atlas [(https://www.cancer.gov/ccg/research/genome-sequencing/tcga](url)), analyzed it with R, and hosted a website with Streamlit.

Access the full website here: [https://st-genefinal-p1u7qn6phok.streamlit.app/](url)
