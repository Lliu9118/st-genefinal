This is a website I made with Emily Wang on visualizing discrepancies between oncogenic gene mutation rates across different races. 

We used a dataset of ~15,000 clinical trials from The Cancer Genome Atlas [(https://www.cancer.gov/ccg/research/genome-sequencing/tcga](url)), analyzed it with R, and hosted a website with Streamlit. This project was later presented at the 2023 Joint Statistical Meetings.

Access the full website here: [https://st-genefinal-p1u7qn6phok.streamlit.app/](url)
